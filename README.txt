============================================================
         KarmayogAI — Setup & Run Instructions
============================================================

REQUIREMENTS
------------
- Python 3.10 or 3.11
- Download from: https://python.org


============================================================
FIRST TIME SETUP (Local)
============================================================

STEP 1 — Go into backend folder
--------------------------------
Mac/Linux:
  cd Desktop/KarmayogAI/backend

Windows:
  cd Desktop\KarmayogAI\backend


STEP 2 — Create Virtual Environment
-------------------------------------
  python -m venv venv


STEP 3 — Activate Virtual Environment
---------------------------------------
Mac/Linux:
  source venv/bin/activate

Windows:
  venv\Scripts\activate


STEP 4 — Install All Dependencies
-----------------------------------
  pip install -r requirements.txt

  NOTE: Takes 5-10 minutes first time
        (torch and transformers are heavy)


STEP 5 — Train ML Models (only once)
--------------------------------------
  python ai_modules/train_models.py

  NOTE: Creates .pkl files in ai_modules/trained_models/
        Only needs to be done once


STEP 6 — Run the App
----------------------
  python app.py


STEP 7 — Open in Browser
--------------------------
  http://localhost:5000

============================================================
DEPLOY TO RENDER (Free Hosting)
============================================================

STEP 1 — Push code to GitHub
------------------------------
  1. Create a new repo at https://github.com/new
  2. In your project folder, run:

       git init
       git add .
       git commit -m "Initial commit"
       git branch -M main
       git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
       git push -u origin main

  IMPORTANT: The .gitignore is already configured to exclude:
    - .env (secrets)
    - venv/, venv_win/ (virtual environments)
    - *.db (database files)
    - *.pkl (ML model binaries — retrained on deploy)
    - logs/


STEP 2 — Create a Render account
----------------------------------
  Go to https://render.com and sign up (free)


STEP 3 — Create a new Web Service
------------------------------------
  1. Click "New" → "Web Service"
  2. Connect your GitHub account and select your repo
  3. Render will auto-detect render.yaml and fill in settings

  OR configure manually:
    - Root Directory:    backend
    - Build Command:     pip install -r requirements.txt && python ai_modules/train_models.py
    - Start Command:     gunicorn "app:create_app()" --bind 0.0.0.0:$PORT --workers 2 --timeout 120
    - Python Version:    3.11


STEP 4 — Set Environment Variables in Render Dashboard
--------------------------------------------------------
  Go to your service → Environment → Add the following:

    SECRET_KEY         → click "Generate" for a random value
    JWT_SECRET_KEY     → click "Generate" for a random value
    FLASK_ENV          → production
    DATABASE_URL       → sqlite:///karmayogai.db
    UPLOAD_FOLDER      → /tmp/uploads
    ALLOWED_ORIGINS    → * (or your frontend domain)
    IGOT_API_KEY       → your actual API key

  NOTE: render.yaml already sets most of these automatically.
        SECRET_KEY and JWT_SECRET_KEY are auto-generated by Render.


STEP 5 — Deploy
-----------------
  Click "Deploy" (or it auto-deploys on every git push)

  First deploy takes ~10-15 minutes (installs torch, trains models).
  Subsequent deploys are faster.


STEP 6 — Access your live app
-------------------------------
  Your app URL will be:
  https://karmayogai.onrender.com  (or similar)


IMPORTANT NOTES FOR RENDER (Free Tier)
----------------------------------------
  - Free tier spins down after 15 minutes of inactivity.
    First request after sleep takes ~30 seconds.
  - SQLite database resets on every redeploy (ephemeral disk).
    For persistent data, upgrade to a paid plan and use PostgreSQL.
  - ML model .pkl files are regenerated on every deploy (via train step).
  - Uploads (/tmp/uploads) are also ephemeral on free tier.


============================================================
COMMON ERRORS & FIXES
============================================================

  python not found
  → Use "python3" instead of "python"

  pip not found
  → Use "pip3" instead of "pip"

  torch install fails
  → Run: pip install torch --index-url https://download.pytorch.org/whl/cpu

  port 5000 already in use
  → Kill the process or use another port

  No module named flask
  → Virtual environment activate karna bhool gaye
  → Run the activate command again

  trained_models not found
  → Run: python ai_modules/train_models.py again

  Render build fails on scikit-learn
  → requirements.txt uses >=1.5.0 (flexible) so this should not happen
  → If it does, check Render logs for the specific error
